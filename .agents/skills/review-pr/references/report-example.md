# 复杂复审报告示例

仅在需要编写复杂 PR 复审报告时阅读。替换所有占位内容；`SKILL.md` 的报告规则、实际
快照和证据优先于本示例。

```markdown
## 审查结论：建议修复后再合并

本轮复审：已修复 <count> · 仍存在 <count> · 新增 <count>；另有 <count> 项决策待确认。

线程状态：最终开放 <count> 条；说明已修复但仍开放、只读未操作或无法确认的实际情况。

CI 与本地验证：仅列出实际结果和限制。

**行动项**

- F1：<短标题和建议动作>。
- Q1：<需要用户确认的范围或行为决策>。

---

## 待处理的已有评论

### [P1] C1 — <评论问题标题>

位置：<准确快照中的代码位置链接>

来源：<评论 permalink>；<当前判断>

**触发与影响：** <可复现条件和用户/系统影响>。

**证据：** <当前代码、diff 或调用链证据>。

**建议修复：** <最小具体修改>。

**建议验证：** <针对性检查>。

---

## 独立发现

### [P1] F1 — <独立问题标题>

位置：<准确快照中的代码位置链接>

来源：本轮新增，或上轮发现、本轮仍成立。

**触发与影响：** <可复现条件和影响>。

**证据：** <当前代码、diff 或调用链证据>。

**建议修复：** <最小具体修改>。

**建议验证：** <针对性检查>。

---

## 待确认决策

### Q1 — <决策标题>

推荐 <选项>，主要取舍是 <取舍>；关联问题使用其稳定 ID。

---

## 旧评论与线程处理记录

- **C2：<评论链接>**：<当前代码证据和判断>；线程状态为 <实际状态>。

---

## 审查范围与验证

**范围与快照**

- 范围：<PR 目标、关联 issue 与审查边界>。
- 远程 Head：<完整 SHA>。
- Base：<完整 SHA>。
- Merge-base：<完整 SHA>。

**本地准备**

- <准备模式、分支/upstream 或 worktree 路径，以及源 checkout 状态>。

**已执行验证与限制**

- 已执行：<实际检查及结果>。
- CI：<通过、失败或 pending>。
- 未运行／受阻：<限制及其对结论的影响>。

**刷新与操作**

- 最终刷新：<head 是否一致、PR updatedAt、线程和回复覆盖情况>。
- 线程计数：初始开放 <count> · 本轮确认 resolve <count> · 最终开放 <count>。
- 实际操作：<本地和远程操作，或明确只读>。
```
