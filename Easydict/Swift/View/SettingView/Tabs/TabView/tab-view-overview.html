设置标签页架构概览

本目录保存设置窗口的七个顶层 SwiftUI 标签页。它负责把偏好、服务、快捷键、隐私与应用信息组织为稳定的设置界面，并把具体业务状态交给 Defaults、LocalStorage、服务对象或对应 view model；不再承担单词本或查询历史浏览。

当前标签集合

标签主要职责状态边界
GeneralTab通用行为、外观、语言和查询偏好。使用配置/Defaults，语言变化通过全局通知传播。
ServiceTab按 Fixed、Mini、Main 窗口类型配置服务、顺序与启用状态。服务数组来自 LocalStorage；变更通过 serviceHasUpdated 通知同步。
DisabledAppTab维护禁用取词的应用列表。只管理禁用应用配置，不控制查询窗口生命周期。
ShortcutTab展示并编辑应用快捷键。快捷键注册由相应模型/管理器负责。
AdvancedTab窗口、取词、OCR、音频及高级行为。复用 AdvancedTabItemView，写入配置后由通知或消费端响应。
PrivacyTab隐私相关开关与说明。保持表单简单，不读取 Wordbook 数据文件。
AboutTab版本、链接与致谢窗口入口。致谢由独立 HostWindowManager 窗口承载。
明确边界：原 Favorites 设置标签已移除。Wordbook 与 Query History 现在共享独立的可复用单词本窗口，从菜单栏入口打开；它们不属于设置偏好，也不能重新加入 SettingTab、本目录或设置窗口尺寸分支。

标签选择与窗口尺寸流

  1. SettingView 以 SettingTab enum 作为 TabView selection，初始为 General；每个标签有稳定 tag。
  2. WindowAccessor 通过一个极小的 NSViewRepresentable 取得承载设置页的 NSWindow，首次取得时执行尺寸计算。
  3. selection 改变时再次计算尺寸。所有标签宽度固定为 900；Disabled 高 500、Privacy 高 340、About 高 300，其余高 720。
  4. 调整时保持窗口顶部位置不跳动，禁用 zoom 按钮，并移除 resizable style，避免不同标签内容引发窗口动画和布局振荡。

ServiceTab 内部结构

ServiceTab 在设置 TabView 内使用嵌入式 HSplitView，而不是再嵌套一个窗口级 NavigationSplitView。左栏宽度 270–320，右栏获取剩余空间。

区域行为持久化/同步
窗口类型选择在 Fixed、Mini、Main 间切换；切换后 selection 回到窗口配置。ViewModel 从 LocalStorage 载入对应窗口的完整服务数组。
窗口配置入口固定在列表顶部且不参与拖拽，右栏展示 WindowConfigurationView。窗口级配置通过其专属 key 和更新通知生效。
服务列表完整排序，不按凭据类型分组；稳定 service id 维持 selection。拖拽把完整 serviceTypeWithUniqueIdentifier 顺序写回 LocalStorage，并发送更新通知后刷新。
凭据标签行内显示 no-key、built-in、key、cli，只表达服务需求。标签不改变排序，也不保存独立状态。
详情区选中服务时以 grouped Form 展示 configurationListItems()；无配置时显示提示。配置写入由服务自身承担。
启用开关普通服务直接启用；流式服务先 validate；Claude Code/Codex CLI 先经风险确认。成功后写 LocalStorage 并发布 serviceHasUpdated；失败显示错误，不写 enabled=true。

正常、失败与恢复流

正常流

  1. 用户切换标签，SettingView 调整固定窗口尺寸；标签视图读取其负责的配置源。
  2. ServiceTab 切换窗口类型或服务 selection，左右栏在同一 ViewModel 内同步。
  3. 拖拽、开关或配置更改写入 LocalStorage，通知消费端及 ServiceTab 自身刷新。
  • 选中服务在刷新后不存在：ViewModel 回退到 windowConfiguration，避免详情持有陈旧对象。
  • 服务校验失败：停止 validating，展示错误 alert，保留原 enabled 状态；用户修正配置后可再次启用。
  • 窗口类型变化：先清除旧服务 selection，再读取新窗口类型数组，防止相同 id 指向错误上下文。
  • 尺寸异常：确认 WindowAccessor 已获得当前窗口、selection tag 与 enum 一致，再检查高度 switch；不要在单个标签内另行修改外层 NSWindow。

调试与验证入口

  • 逐一切换七个标签，确认宽度始终 900、高度分别命中规则、顶部位置保持且窗口不可缩放；确认界面中没有 Favorites 标签。
  • ServiceTab 布局异常时，确认仍为内嵌 HSplitView；selection 异常时检查 ServiceTabSelection 是否使用 windowConfiguration 或稳定 service id。
  • 排序或标签异常时，确认 ServiceItems 遍历完整 viewModel.services，并检查凭据 requirement 到四种 badge 的映射。
  • 服务状态异常时，从 validate/risk alert 进入，确认只有成功路径调用 LocalStorage setService 与 postServiceUpdateNotification。
  • 从菜单栏打开 Wordbook，确认它出现在独立窗口且 Settings selection/尺寸完全不变；从历史重放也不应打开设置页。
