单词本模块架构概览

本目录实现“保存一条带语言方向的查询，并能安全整理、检索、导出和再次查询”的完整功能。核心数据按 Store → Repository → Manager / ViewModel → 查询窗口星标 / 单词本窗口 单向分层；持久化错误不能伪装成空数据，异步旧回调也不能改变当前查询的星标。

职责与非职责

  • 负责单词条目、分组、默认分组、搜索排序、CSV 导出、旧 Favorites 一次性迁移，以及损坏或未来版本数据的保护式恢复。
  • 负责向 Objective-C 查询标题栏提供可查询、可增删的主线程桥接，并向独立 SwiftUI 单词本窗口提供可观察状态。
  • 查询历史仍由 QueryRecordManager 和 Defaults 的 queryHistory 管理；本模块只投影、导出、删除或把历史项加入单词本，不把历史写进 wordbook.json。
  • 翻译服务执行、查询窗口选择和 AppKit 窗口布局属于外部边界，本目录只提交“以保存的原文和语言方向重新查询”的意图。

数据与进出边界

磁盘边界：wordbook.json 是主快照，wordbook.backup.json 是已验证轮换备份，wordbook.corrupt.<timestamp>.json 保存损坏或重置前的原始字节。模型包含 schemaVersion、entries、groups 和 defaultGroupID。

Defaults 边界：旧 Favorites 只作为一次性迁移输入且不被删除；迁移版本只在候选快照连续两次安全保存后推进。查询历史及窗口的 section/sort 偏好继续留在 Defaults。

查询边界：条目身份由修剪边缘空白、忽略大小写但保留内部空白与重音差异的 WordbookEntryKey 决定。再次查询把保存的原文、源语言和目标语言原样交给 EZWindowManager。

正常流程

首次加载与迁移

  1. Manager 或 ViewModel 订阅 Repository 状态并触发共享的惰性加载任务。
  2. Store 读取主文件；不存在时尝试孤立备份，否则返回空快照。Repository 再执行语义校验与可修复引用清理。
  3. 若迁移版本落后，Migrator 合并旧 Favorites，Repository 验证并连续保存候选快照，使主文件和备份都包含迁移结果，最后更新迁移标记。
  4. Repository 重建 key/id 索引，发布 ready；标题栏星标和独立窗口从同一快照刷新。

保存、管理与重放

  1. 查询标题栏传入当前可见原文和已解析语言方向，星标先 lookup；缺失时 add，已存在时 remove。含备注的删除必须二次确认。
  2. 窗口内创建分组、编辑备注、移动或批量删除时，ViewModel 先关闭本地 mutation gate，再由 Repository 串行执行事务。
  3. 事务先生成并验证候选快照，Store 原子保存并校验后才替换内存快照、重建索引和发布状态。
  4. 点击条目或历史记录时，ViewModel 以保存的语言方向调用 WindowManager；CSV 导出使用完整句式本地化、当前 locale 和确定性转义。

失败、回滚与恢复

  • 写入失败：Store 在覆盖前验证并轮换旧主文件；新主文件写入或校验失败时恢复备份。Repository 不提交候选快照，ViewModel/星标保留可重试动作。
  • 损坏主文件：先把原始字节归档为 corrupt 文件，再只从通过结构校验的备份恢复；恢复成功发布提示，失败则进入 protected，绝不显示“空单词本”。
  • 未来 schema：只读取 JSON header 即进入 newerSchema 保护态，禁止写入和普通 reset，提示用户升级应用并可在 Finder 定位数据。
  • 主文件与备份都不可用：恢复视图提供重试、显示目录与经确认的保护式重置。重置先归档现有文件，再创建并验证空快照。
  • 并发或旧 UI 意图：Repository 写门串行化跨 await 的事务；窗口 mutation gate 阻止重复提交，星标的 generation/mutation id 阻止旧查询回调覆盖新查询。

测试与手工入口

六个核心测试套件覆盖模块的非 UI 行为：

  • WordbookModelsTests：身份规范化和模型语义。
  • WordbookQueryTests：范围、搜索、排序和历史投影。
  • WordbookMigrationTests：旧 Favorites 合并、幂等与冲突。
  • WordbookStoreTests：原子写、备份、损坏归档、未来 schema 与保护式重置。
  • WordbookRepositoryTests：加载发布、事务回滚、串行写和分组确认。
  • WordbookCSVExporterTests：列顺序、语言/分组显示名和 RFC 4180 转义。

手工检查从菜单栏打开单词本窗口，验证查询星标增删、含备注删除确认、分组重排与非空删除、搜索/排序/批量操作、Wordbook/History 导出、历史重放、切换六种语言、红色关闭后重开状态复用，以及模拟损坏/未来 schema 后的 Finder、重试与重置路径。
