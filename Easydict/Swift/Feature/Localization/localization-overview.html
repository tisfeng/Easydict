Easydict 本地化模块概览

本目录负责应用界面语言的选择、系统语言识别和运行时资源包切换。 翻译内容由 Localizable.xcstrings 与 InfoPlist.xcstrings 管理；本目录不负责翻译服务的源语言或目标语言能力。

职责与边界

  • LanguageState.swift 定义可选界面语言、显示名称和用户偏好。
  • I18nHelper.swift 解析偏好或系统区域设置，并定位对应的 .lproj。
  • LocalizedBundle.swift 将字符串查询转发到当前语言资源包。
  • NSBundle+Localization.m 在启动时替换主资源包的字符串查找行为。
  • String Catalog 是文案的唯一来源；服务提供商的语言映射属于各 Service 模块。

运行流程

  1. 启动时读取 LanguagePreferenceLocalKey；没有有效偏好时检查系统语言。
  2. Locale.languageType 按语言、文字和地区组合匹配支持的界面语言。
  3. I18nHelper 使用语言代码打开对应的 .lproj 资源包。
  4. SwiftUI 与 AppKit 的本地化查询经 LocalizedBundle 返回当前语言文案。
  5. 用户切换语言后发布通知，使依赖界面语言的视图刷新。

若偏好无效或资源包缺失，语言代码回退到英语，资源包查找最终回退到主 Bundle。

添加或维护语言

  1. 在 LanguageState.LanguageType 注册稳定的 BCP 47 语言代码和原生显示名称。
  2. 为两个 String Catalog 的每个键补齐目标语言，保留占位符、URL、格式和产品名称。
  3. 在 Xcode 项目的 knownRegions 注册语言代码。
  4. 验证 JSON、键覆盖率、占位符一致性，并审查差异中是否混入无关改动。

故障与调试入口

  • 语言未显示：检查枚举是否包含该代码，以及显示名称分支是否完整。
  • 系统语言未命中：检查 Locale.languageType 的语言、文字、地区组合。
  • 文案仍为英语：确认目标语言单元存在、资源已生成，并检查 localizedBundle 路径。
  • 格式异常：比较英语与目标语言中的 printf 占位符、插值变量、标签、换行和 URL。
  • 基础验证无需启动应用；编译风险或资源生成异常时再运行 Xcode 构建。
