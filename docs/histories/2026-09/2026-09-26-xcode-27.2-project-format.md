工作区的 diff 行数很大（`project.pbxproj` 198 增 192 删），但绝大多数来自 Xcode 重新序列化，
不是人工改动。用 `plutil -convert json` 把两个版本解析为对象图后对比，实质差异仅有两处，因此
本提交的语义范围就是「格式规范化 + 版本标记升级」。

`DEVELOPMENT_TEAM` 必须还原：`0ac50d9fe`（`chore(project): Use variable for Xcode development
team`）与 `46f22a861`（`fix(signing): standardize DEVELOPMENT_TEAM configuration across project
targets`）两次提交专门把硬编码团队改为变量，理由写明避免提交用户特定设置。Debug 之所以能用
ad-hoc 身份免签名构建，依赖 `Easydict-debug.xcconfig` 把 `DEVELOPMENT_TEAM` 置空并令

`$(DEVELOPMENT_TEAM)` 都会解析到该团队，`scripts/setup-team.sh` 的变量覆盖方式也随之失效。
Release 配置的硬编码团队保持不变，属于既有约定。
