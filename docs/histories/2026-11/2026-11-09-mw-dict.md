### 设计意图

韦氏网站由 Cloudflare 拦截，非浏览器客户端 403，抓取不可行；官方 API 提供同一部词典的
结构化数据，因此改用 API + 用户免费 Key。解析器只依赖 Foundation，义项编号按 API 的
“首项完整编号 + 后续字母”规则合成；渲染复用原生 part 与 synonyms 字段，保持与必应卡片
一致的交互。
