### 设计意图

必应词典 JSON API 匿名 403，但 `dict/search` 页面匿名 200 且双语词义服务端直出，因此绕开
既有 `BingService` 的 v7 API/降级链路，以独立词典服务解析服务端 HTML；解析器保持纯
Foundation 以脱离 app target 独立编译验证，也便于 fixture 回归。渲染走原生
`EZTranslateWordResult`（不使用 WebView HTML 卡片），并按官网顺序输出：快速释义 → 变形 →
搭配 → 同义词/反义词 → 编号释义；每条编号释义独立成 part，避免原生卡片用 `; ` 合并成一段。
