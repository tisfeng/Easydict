## 用户请求

## 设计意图

让 `git-commit` 成为单提交结果的唯一报告契约，避免调用工作流各自维护不一致的模板。
文本行统计由可测试脚本从 Git 原始数据计算，`worktree-rebase-merge` 只补充提交来源和
集成状态。

## 主要变更

- 为 `git-commit` 增加基于 Git numstat 的确定性统计脚本，互斥统计代码与文档文本变动。
- 增加临时 Git 仓库行为测试，覆盖混合文件、分类、重命名、中文和空格路径、删除、
  多提交区间、空提交与无效 revision。
- 规定成功提交必须展示完整提交哈希、完整实际提交信息、工作树、push 和三组文本变动统计。
- 让 `worktree-rebase-merge` 区分本次创建和复用已有提交；单提交复用统一报告，多提交
  使用提交列表与区间统计。
- 在仓库自动提交规则中明确完整提交结果属于交付的一部分。
