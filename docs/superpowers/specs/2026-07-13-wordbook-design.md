# Easydict 单词本设计

- 日期：2026-07-13
- 状态：已通过产品设计确认，等待实施计划

## 1. 背景

Easydict 已有收藏与查询历史功能：查询窗口可以把当前文本加入收藏，
设置页能够浏览、删除、重新查询并导出收藏和历史。现有模型只保存查询文本、
语言对与时间，并将整个数组写入 Defaults；它更接近“收藏列表”，不具备长期
管理单词、短语、句子和段落所需的分组、备注、独立入口与可靠持久化能力。

本设计参考欧路词典“我的生词本”的管理流程，包括醒目的分组切换、列表筛选、
排序和集中管理，但保持 Easydict 的轻量定位。第一期不复制欧路的释义快照、
卡片播放、熟悉度、背词算法或云同步。

参考资料：

- [欧路词典：我的生词本](https://docs.eudic.net/1/shi-yong-zhi-yin/wo-de-sheng-ci-ben)
- [Easydict Issue #33：建议新增类似生词本的功能](https://github.com/tisfeng/Easydict/issues/33)
- [Easydict Issue #902：单词、句子记录与导出需求](https://github.com/tisfeng/Easydict/issues/902)

## 2. 目标

第一期交付一个完全本地的管理型单词本：

1. 支持保存任意非空查询文本，包括单词、短语、句子和段落。
2. 在查询窗口中通过空心或实心星标一键添加和移除条目。
3. 提供独立、可调整大小的单词本窗口，不再把内容管理放在设置页。
4. 支持单层分组、可配置默认分组、搜索、排序、备注和批量管理。
5. 在同一窗口保留查询历史，并允许从历史直接加入单词本。
6. 自动、无损地迁移现有 Favorites 数据，同时保持查询历史不变。
7. 使用版本化 JSON 文件可靠保存约一万条个人数据，并保留有效备份。
8. 保留并增强 CSV 导出，不增加文件导入。

## 3. 非目标

第一期明确不包含：

- 自动保存翻译服务结果、词典释义或 HTML 内容。
- 自动抓取其他应用中所选文本的周边语境。
- 卡片播放、熟悉度、测验、学习计划、统计或间隔重复算法。
- 云同步、账号系统、欧路账号或 OpenAPI 对接。
- CSV 或其他外部文件导入。
- 一个条目属于多个分组、标签系统或分组层级。
- 修改条目的原文或源/目标语言。
- 用数据库、Core Data 或新的第三方存储依赖替代 JSON。

## 4. 已确认的产品决策

| 主题 | 决策 |
|---|---|
| 收录内容 | 任意查询文本 |
| 释义 | 不保存；查看时重新查询 |
| 补充信息 | 一个可编辑备注字段 |
| 分组关系 | 每个条目最多属于一个平级分组 |
| 默认分组 | 初始为“未分组”，用户可设置任意分组为默认 |
| 主入口 | 菜单栏打开独立窗口 |
| 查询入口 | 查询窗口显示星标切换按钮 |
| 历史 | 与单词本同窗，通过顶部分段控件切换 |
| 旧收藏 | 自动迁入“未分组” |
| 导入导出 | 仅导出 CSV，不导入 |
| 容量目标 | 约一万条 |
| 持久化 | Application Support 中的版本化 JSON 与备份 |
| 视觉流程 | 参考欧路的顶部控制与单栏列表，不采用三栏管理界面 |

## 5. 架构

新代码集中在 `Easydict/Swift/Feature/Wordbook/`，由以下组件组成。

### 5.1 WordbookStore

`WordbookStore` 是唯一接触文件系统的 actor，负责：

- 计算 Application Support 下的数据路径。
- 读取主文件和备份文件。
- 识别快照版本。
- 编码、验证并原子写入 JSON。
- 在主文件损坏时恢复备份。
- 保留损坏文件供用户排查。

它不包含分组、去重或迁移等产品规则。

### 5.2 WordbookRepository

`WordbookRepository` 是单词本的唯一业务数据源，负责：

- 持有当前内存快照和条目唯一键索引。
- 串行执行所有修改，避免并发写入覆盖。
- 添加、移除和更新条目。
- 创建、重命名、排序和删除分组。
- 设置默认分组并修复失效引用。
- 执行旧 Favorites 迁移。
- 先持久化候选快照，成功后才发布新状态。
- 向 SwiftUI 和 Objective-C 桥接层发布变更。

Repository 不依赖具体界面，因此未来可以在不修改消费者的情况下更换存储实现。

### 5.3 WordbookManager

`WordbookManager` 是面向现有 Objective-C 查询窗口的轻量桥接层，提供：

- 查询当前文本是否已在单词本中。
- 添加当前查询到默认分组。
- 移除当前条目。
- 将 Repository 的变更转换为 Objective-C 可观察通知。

标题栏不读取文件，也不复制 Repository 的业务规则。

### 5.4 WordbookViewModel

`WordbookViewModel` 在主线程管理窗口状态：

- 单词本与查询历史的当前区域。
- 当前分组和列表选择。
- 搜索文本与排序方式。
- 批量选择、编辑面板和错误提示。

搜索与排序只处理 Repository 已发布的内存快照，不产生磁盘访问。

### 5.5 HostWindowManager 扩展

复用现有 `HostWindowManager` 承载 SwiftUI 根视图，并增加专用的单词本窗口入口。
该入口以固定 window ID 查找窗口：已有窗口时只激活并置前，窗口不存在时才按
900 × 640 的默认尺寸创建。这样既保留列表选择和搜索状态，也避免再增加一个只服务
单词本的窗口管理器。

### 5.6 查询历史

`QueryRecordManager` 继续管理现有查询历史，不迁入 WordbookStore。单词本窗口通过
一个只负责展示和操作历史的适配层使用它。原 Favorites 写入路径在迁移后停用。

### 5.7 依赖方向

依赖保持单向：

```text
查询窗口 / 单词本窗口
        ↓
WordbookManager / WordbookViewModel
        ↓
WordbookRepository
        ↓
WordbookStore
```

不新增第三方依赖。

## 6. 数据模型

### 6.1 WordbookEntry

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 条目稳定标识 |
| `text` | String | 保留用户查询时的原始大小写、空格与换行 |
| `fromLanguage` | Language | 查询源语言 |
| `toLanguage` | Language | 查询目标语言 |
| `groupID` | UUID? | `nil` 表示“未分组” |
| `note` | String | 用户自由填写的释义、语境或学习提示 |
| `createdAt` | Date | 首次加入时间 |
| `updatedAt` | Date | 最近修改备注或分组的时间 |

原文与语言对在第一期只读。备注允许为空。

### 6.2 WordbookGroup

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 分组稳定标识 |
| `name` | String | 用户可见名称 |
| `sortOrder` | Int | 用户设置的显示顺序 |
| `createdAt` | Date | 创建时间 |

“未分组”是由 `groupID == nil` 表示的虚拟分组，不写入 groups 数组，也不能删除或
重命名。

### 6.3 WordbookSnapshot

| 字段 | 类型 | 说明 |
|---|---|---|
| `schemaVersion` | Int | 第一版固定为 `1` |
| `entries` | [WordbookEntry] | 全部单词本条目 |
| `groups` | [WordbookGroup] | 全部用户分组 |
| `defaultGroupID` | UUID? | `nil` 表示默认加入“未分组” |

界面偏好，例如当前分段、当前分组和排序方式，可以使用 Defaults 保存；单词本内容
只能写入快照文件。

## 7. 唯一性与数据校验

条目唯一键由以下三部分组成：

1. 对原文执行 Unicode 规范化、去除首尾空白并进行大小写折叠。
2. 源语言。
3. 目标语言。

内部空白和换行不会被折叠，变音符号不会被移除。同一原文使用不同语言对时可以
分别收藏。重复添加返回已存在的条目，不创建副本，也不覆盖其分组或备注。

其他校验规则：

- 去除首尾空白后为空的文本不能加入。
- 分组名称去除首尾空白后不能为空。
- 分组名称不允许大小写无关的重名。
- 无效 `groupID` 在加载时修复为 `nil`。
- 无效 `defaultGroupID` 在加载时修复为 `nil`。
- 删除默认分组时，同时把默认分组重置为“未分组”。

## 8. 文件布局与写入语义

文件存放在：

```text
<Application Support>/<bundle identifier>/Wordbook/
├── wordbook.json
├── wordbook.backup.json
└── wordbook.corrupt.<timestamp>.json
```

损坏文件只在恢复流程产生。

每次修改采用以下顺序：

1. Repository 基于当前快照构造并校验候选快照。
2. Store 将当前有效主文件原子复制并替换为备份。
3. Store 将候选快照编码到临时文件并原子替换主文件。
4. Store 重新解码主文件，确认写入内容有效。
5. 验证失败时，Store 从备份恢复主文件并返回错误。
6. 验证成功后，Repository 才替换内存快照并发布变更。

任何一步失败时，Repository 保留修改前的内存状态。星标、列表和默认分组不会显示
未成功落盘的状态。

## 9. 旧 Favorites 迁移

迁移版本使用 Defaults 中的整数标记，第一期迁移版本为 `1`。

Repository 第一次成功加载后，如果迁移版本小于 `1`：

1. 读取现有 `Defaults.favorites`。
2. 将每个 QueryRecord 转换为 WordbookEntry。
3. 保留原 ID、原文、语言对和收藏时间。
4. `groupID` 设为 `nil`，`note` 设为空字符串，两个时间字段使用原收藏时间。
5. 按新唯一键跳过已经存在的条目，保证迁移可重复执行。
6. 原子保存并重新读取验证。
7. 只有验证成功后才把迁移版本设置为 `1`。

旧 Favorites 数组在第一期保留但不再写入，以支持版本回退。迁移失败不设置标记，
下次启动继续尝试。查询历史不参与迁移。

## 10. 独立窗口设计

窗口默认尺寸为 900 × 640，可由用户调整大小，并保持单实例。

### 10.1 顶部区域

- “单词本 / 查询历史”分段控件。
- 当前分组名称与条目数量；点击后显示分组切换菜单。
- 搜索框。
- 排序、批量操作和导出菜单。

分组菜单列出“全部条目”“未分组”和用户分组，并提供：

- 新建分组。
- 重命名分组。
- 调整平级顺序。
- 删除分组。
- 设置默认分组。

默认分组显示明确标记。删除非空分组时需要确认，确认后所有关联条目移动到“未分组”。

### 10.2 单词本列表

单栏列表行显示：

- 原文摘要。
- 备注摘要；空备注不占额外空间。
- 源语言到目标语言。
- 添加时间。

列表支持：

- 在当前分组内搜索原文和备注。
- 默认按添加时间从新到旧排序。
- 按添加时间从旧到新排序。
- 按原文字母顺序排序。
- Command 多选后批量移动或删除。
- 双击或按 Return 重新查询。
- 行菜单编辑备注、移动分组、复制原文或删除。

编辑面板完整显示原文、语言对、分组、创建时间和修改时间。原文与语言只读，备注与
分组可修改。备注点击保存后一次性提交，不在每次键入时写磁盘。

### 10.3 查询历史

查询历史使用同样的单栏结构，每行提供：

- 重新查询。
- 星标加入默认分组。
- 删除。

切换到查询历史时隐藏分组控件；搜索框匹配查询原文，默认按时间从新到旧排序，并可
切换为从旧到新。搜索词不改变历史导出范围。历史仍由 QueryRecordManager 管理并保持
现有 1000 条上限。

### 10.4 菜单与设置页

- 菜单栏增加本地化的“单词本…”入口。
- 原设置页“收藏”标签移除。
- 单词本是内容窗口，不包含在 Settings 场景中。

## 11. 查询窗口星标

查询窗口标题栏增加始终可见的星标按钮：

- 空查询时禁用。
- Repository 初次加载或迁移期间禁用，并显示进行中状态。
- 当前唯一键不存在时显示空心星。
- 当前唯一键存在时显示实心星。
- 点击空心星把条目加入当前默认分组。
- 点击实心星移除条目。
- 移除带备注的条目之前需要确认。
- 持久化进行中按钮禁用，并展示平台一致的进行中状态。

查询文本或语言对变化时，WordbookManager 异步查询 Repository 索引。结果返回时必须
再次核对查询唯一键，避免旧请求覆盖新查询的星标状态。

Repository 成功发布新快照后：

- SwiftUI 窗口通过可观察状态刷新。
- Objective-C 标题栏通过通知刷新。

## 12. 重新查询

从单词本或历史重新查询时，必须恢复保存的原文、源语言和目标语言。不能只把原文传给
当前全局语言配置。具体桥接应复用现有查询窗口路由，避免在 Wordbook 模块中复制查询
服务调度逻辑。

## 13. 搜索与排序

搜索范围由当前分组决定：

- “全部条目”搜索全部条目。
- “未分组”只搜索 `groupID == nil` 的条目。
- 用户分组只搜索对应 `groupID`。

搜索匹配原文和备注，使用本地化、大小写无关的包含判断。搜索词不会改变 CSV 导出
范围。搜索和排序都在内存快照上执行，不访问文件系统。

## 14. CSV 导出

单词本 CSV 使用 UTF-8、逗号分隔和 CRLF 行结束符。包含逗号、双引号或换行的字段使用
双引号包裹，字段内双引号写成两个双引号。字段为：

```text
text,fromLanguage,toLanguage,note,group,createdAt,updatedAt
```

- 语言使用当前界面的本地化名称，与现有导出行为一致。
- 时间使用 ISO 8601。
- “未分组”使用对应本地化名称。
- 选择“全部条目”时导出全部条目。
- 选择具体分组或“未分组”时只导出该范围。
- 当前搜索词不缩小导出内容。

查询历史继续使用现有 CSV 字段。导出失败只显示错误，不修改任何应用数据。

## 15. 失败处理与恢复

### 15.1 主文件损坏

1. 保留带时间戳的损坏文件。
2. 尝试解码备份。
3. 备份有效时恢复主文件，并提示可能缺少最近一次修改。
4. 备份也无效时进入保护状态，不创建或覆盖空文件。

保护状态提供重试、在 Finder 中显示数据文件和确认重置三个操作。

### 15.2 不支持的版本

如果 `schemaVersion` 高于当前应用支持的版本，只读取版本头，不把条目解码为 v1
模型。窗口进入不可编辑的保护状态，提示升级应用，并允许在 Finder 中显示数据文件。
旧版本不得覆盖新格式文件。

### 15.3 写入失败

磁盘空间、权限或编码错误发生时：

- 内存保持修改前状态。
- 星标和列表不显示未保存结果。
- 提供本地化错误与重试入口。

### 15.4 用户删除

- 批量删除需要确认。
- 删除非空分组需要确认。
- 从查询窗口移除带备注的条目需要确认。
- 删除分组只移动条目，不删除条目。

## 16. 本地化、可访问性与工程约束

- 所有新增可见文案使用小写、点分层的 String Catalog key。
- 更新 `en`、`es`、`ja`、`sk`、`zh-Hans`、`zh-Hant` 六种语言。
- 使用 SFSafeSymbols，不新增硬编码 SF Symbol 字符串。
- SwiftUI 使用 `foregroundStyle` 等当前 API。
- 星标、默认分组和错误状态不能只依赖颜色表达，并提供可访问性标签与提示。
- 列表、分组菜单、搜索和主要操作支持标准键盘焦点与 VoiceOver 朗读顺序。
- 新文件登记到正确 PBXGroup；HTML、SVG 和规格文档不加入 Resources。
- `Easydict/Swift/Feature/Wordbook/` 包含中文 `wordbook-overview.html` 和
  `wordbook-architecture.svg`，覆盖职责、数据流、故障恢复和测试入口。
- 每个 Swift 文件只承担一个主要类型或明确职责，通常保持在 500 行以内。
- 不向现有大型 Objective-C 查询控制器加入复杂业务；只做必要桥接。

## 17. 测试策略

生产代码与单元测试由不同 agent session 修改。Wordbook 核心行为需要高信号单元测试，
UI 变化使用手动验证，不为 SwiftUI 布局增加低价值测试。

### 17.1 单元测试

- schema version 1 的 JSON 往返编码。
- 大小写折叠、首尾空白和语言对参与去重。
- 重复添加不覆盖备注和分组。
- 默认分组设置与删除后的回退。
- 删除分组把条目移动到“未分组”。
- 备注与分组修改更新 `updatedAt`。
- Favorites 迁移保留 ID、文本、语言和时间。
- 迁移重复执行不会新增副本。
- 保存失败不发布候选快照。
- 主文件损坏后恢复有效备份。
- 主文件和备份同时损坏时进入保护状态。
- 高版本文件不会被覆盖。
- 当前分组内的搜索和三种排序。
- CSV 特殊字符、换行和双引号转义。
- 一万条数据的加载、索引、搜索、排序和导出冒烟验证。

### 17.2 手动验证

- 菜单栏重复点击通过 HostWindowManager 只激活一个窗口，并保留当前搜索和选择状态。
- 查询窗口与单词本窗口星标状态双向同步。
- 空查询不能加入单词本。
- 添加、移除、备注、移动和默认分组在重启后保持。
- 历史能够重新查询并加入单词本。
- 重新查询恢复保存的语言对。
- 搜索词不改变导出范围。
- 键盘、多选、窗口缩放和错误提示符合 macOS 习惯。
- 六种语言下无缺失 key、截断的关键操作或硬编码文案。
- VoiceOver 能区分空心/实心星标、默认分组和错误状态。

测试源码变化后，首次验证运行针对 Wordbook 测试套件的 `xcodebuild test`；随后运行完整
应用构建。两个 xcodebuild 命令不得并发使用同一 DerivedData。

## 18. 验收标准

功能满足以下全部条件后视为完成：

1. 现有 Favorites 在首次启动后无损、幂等地迁移到“未分组”。
2. 任意非空查询文本可以通过星标加入默认分组，并能再次移除。
3. 星标只反映已经成功持久化的数据，多个窗口状态一致。
4. 用户可以创建、重命名、排序、删除和设置默认分组。
5. 用户可以搜索、排序、多选、移动、删除、添加备注和重新查询。
6. 查询历史仍可查看、删除、导出，并能直接加入单词本。
7. CSV 按当前分组范围正确导出，内容可以处理逗号、引号和换行。
8. 主文件损坏时能够恢复最近有效备份；无法恢复时不会覆盖用户文件。
9. 一万条测试数据可以在不进行主线程磁盘 I/O 的情况下完成列表搜索和排序。
10. Wordbook 单元测试、应用构建、本地化检查和 Xcode 文件引用检查全部通过。
