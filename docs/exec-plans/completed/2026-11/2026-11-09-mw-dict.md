## 背景

必应词典服务已落地。用户要求以相同要求接入 Merriam-Webster，并尽量贴近官网内容与格式。
实测韦氏网站由 Cloudflare 托管，`curl` 与 `URLSession` 均返回 403 挑战页，只有真实浏览器
可访问；官方 `dictionaryapi.com` 返回同一部 Collegiate 数据，但需要免费 API Key。用户
选择使用官方 API 并提供 Key。

## 目标与范围

- 目标结果：新增 `MerriamWebster` 词典服务，原生卡片按官网顺序展示词性、发音、词形变化、
  动词分节、编号义项与例句、派生词、同义词、首次使用与词源。
- 允许修改路径：`Easydict/Swift/Service/Dictionary/`、服务注册点、本地化、资源目录、
  `EasydictTests/Service/`、`docs/`。
- 同任务 history：`docs/histories/2026-11/2026-11-09-mw-dict.md`
- 用户限制：需要真实 API 验证；卡片内容与官网尽量一致。
- 非目标：Thesaurus 词库接入、同形异义词切换、例句展开。
- 验收标准：解析器与服务层单测通过；真实 API 下 develop / run / happy 与官网结构一致；
  部署版应用窗口可见卡片。

## 步骤

1. 复测网站可达性并确认 API Key 路径。
2. 实现 `MWDictRequest`、`MWDictAPIParser`、`MWDictService`，抽取共享
   `DictionarySupport`（单词判定与查询值编码）。
3. 注册服务类型、工厂、图标、本地化、Key 存储与 scheme 白名单。
4. 编写解析器与服务层单测。
5. 用真实 API 校准义项编号、词形来源、同义词与标记转换。
6. 构建 Release、部署、启用服务并截图核对。

## 风险

- Cloudflare 可能进一步限制 API；Key 可能失效。
- API 结构变化会导致解析失败（已有 fixture 兜底）。
- 义项编号依赖 API 的 `sn` 规则，需回归样本。

## 验证

- `xcodebuild test`：必应与韦氏共 19 项用例通过。
- 真实 API：develop / run / happy 对照官网通过。
- 部署版应用 HTTP 与窗口截图核对通过。
