## 工作计划

1. 先按用户优先级将已提交的 DeepSeek OCR 与 Codex 高级设置更新到原 PR。
2. 接通图片增量，在主线程有序处理并校验请求身份。
3. 读取本机 Codex model/list，按实际模型显示强度并修正已确认的不兼容旧值。
4. 用户确认初版原文逐步显示后，复用原文公式预览，并让本机文字翻译复用现有 App Server 增量。
5. 运行回归、真实模型与本机验收，审查、归档并创建本地提交。

## 风险与决策

- 原文约 80ms 最多更新一次，识别完成后才自动复制或启动翻译。普通 OCR 保留一次结果路径。
- 每次更新核对请求、模型、图片、动作、输入和语言；首段纯空白暂存至出现内容，保护语言状态。
- 使用 #1375 的同一个 MarkdownLabel 与数学缓存，未闭合公式保持原文；一次自动切换后尊重手动返回 LaTeX 源文。
- 本机文字翻译使用已有独立临时 App Server 线程，保留取消、用量、模型和思考配置；空模型沿用 CLI 默认。独立 exec runner 保留原实现。
- 强度菜单读取实际调用的本机 CLI 的模型能力，成功确认 Luna 不支持旧 minimal 后改为 Low。读取失败或未知模型保留已保存选择，托管模式沿用自身版本目录。
