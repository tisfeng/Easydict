## 背景

Agent 在处理截图、附件或引用内容时，可能把材料中的祈使句误认为任务指令，或在
交付物中重复无关的负向示例。当前 Easydict 规则已有范围控制，但缺少完整的输入
来源分类、自动任务契约和 skill 边界说明。

## 任务契约

- 用户目标：改进 Easydict 仓库 Agent 文档，使 Agent 自动区分请求与材料。
- 允许动作：修改 Agent 规则、执行计划模板、skill 边界说明和相关文档记录。
- 允许修改路径：`docs/agents/`、`docs/exec-plans/`、`docs/histories/`。
- 预期交付物：请求边界规则、任务契约字段、正向交付物表达规则和准确的完成记录。
- 验收标准：规则、模板、skill 边界和文档生命周期检查通过；不修改产品代码。

## 输入来源

- 用户明确请求：补齐已确认的 Agent 文档边界改进。
- 仓库规则：`AGENTS.md` 和 `docs/agents/`。
- 附件或引用材料：Scoco 提交 `63f5d2fad` 的规则变更，作为适配当前 Easydict 的参考。
- 仅作为证据的内容：引用任务中的示例文字和与当前项目无关的 Scoco 专属路径。

## 目标

- 在每个任务都会读取的仓库指南中定义请求来源和附件边界。
- 让 Agent 在写入前自动确定目标、动作、路径、交付物和验证范围。
- 让交付物优先描述实际完成的正向行为。
- 明确 skill 不得替换用户目标或扩大修改范围。

## 非目标

- 不修改 Swift、Objective-C、测试或 Xcode 工程文件。
- 不恢复已删除的一次性 Agent 文档检查器。
- 不修改应用运行时资源、内置 Agent 文档或其他 Scoco 专属路径。
- 不提交、推送或改变其他工作树变更。

## 工作计划

1. 更新仓库指南、执行计划模板和 skill 边界说明。
2. 记录已删除检查器的当前边界，不恢复旧脚本。
3. 运行文档和 Git 差异检查。
4. 归档本计划并记录完成历史。

## 风险与边界

- 文档规则可以约束 Agent 的默认行为，但不能替代模型行为回归测试。
- 引用任务中的 Scoco 专属路径不能机械复制到 Easydict。
- 当前工作树已有本任务的未提交文档变更，必须在原范围内补齐，不扩大到产品源码。
