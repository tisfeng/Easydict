# 外部 Agent 资产统一版本治理设计

- 状态：adopted
- 初次记录：2026-09-08
- 最近更新：2026-09-11

## 背景

Easydict 需要直接从仓库运行共享 Skills，并让安装内容可离线审查和历史复现。只引用全局目录
缺少稳定证据，项目各自修改副本又会产生行为和安全差异。

## 设计决策

采用“外部权威来源 + 仓库内完整快照 + lock 校验 + 宿主规则保留项目差异”：

- 外部仓库统一维护通用内容，项目提交可离线读取和运行的完整快照。
- lock 记录来源和预期哈希，通过重算检查本地漂移，而不替代实际安装内容。
- 项目差异保留在宿主规则中，不通过本地修补或 fork 通用 Skill 实现。
- 独立第三方 Skill 保持自身来源；项目专属 Skill 继续由 Easydict 维护。

现行治理规则以 [`docs/agents/README.md`](../agents/README.md#外部-skill-资产) 为准；上游版本
和同步命令记录在 [`docs/references/`](../references/) 中。

## 取舍

- 仓库会保存较大的第三方快照，以换取离线可用、可审查和可回滚。
- 跟踪可移动分支时需要额外记录同步 commit；上游提供稳定 tag 后应优先采用 tag。

## 重新评估条件

- 安装器改变 lock、hash 或安装目录。
- 上游改变仓库、发布方式或 Skill 路径。
- 项目差异无法继续由宿主规则表达。
